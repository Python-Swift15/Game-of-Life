## Game of Life 🧬✨

A polished and customizable cellular automata simulator built with Python 3 and Tkinter. Explore evolving patterns across a grid of cells, experiment with four different rule sets, generate random worlds, and customize the simulation’s appearance and speed. Designed with a clean, relaxing interface for experimenting with how simple rules can create surprisingly complex patterns. 🌌🔬

# Features

* 🧬 Interactive cellular automata simulation
* 🎮 Four different rule sets to experiment with
* 🌱 Watch complex patterns emerge from simple rules
* 🎲 Random world generation
* 🖱️ Click cells to create your own starting patterns
* ▶️ Start and resume simulations
* ⏸️ Pause simulations at any time
* 🎛️ Adjustable simulation speed
* 🎨 Customizable cell colors
* 🌑 Customizable background colors
* ☀️ Light and dark appearance options
* 🧹 Clear and reset the grid
* 🏠 Main menu for changing simulation settings
* ⌨️ Spacebar start/pause controls
* 🖱️ On-screen controls for easier use
* 📱 Button-based controls suitable for touchscreen devices
* ✨ Smooth and relaxing visual experience
* 🖥️ Clean Tkinter graphical interface

# Requirements

* Python 3.x
* Tkinter

# How to Use

1. Launch the program. 🚀
2. Choose one of the four available rule sets. 🧬
3. Customize the simulation appearance and speed. 🎨
4. Create cells manually or generate a random pattern. 🎲
5. Press Start or the Spacebar to begin the simulation. ▶️
6. Watch the cells evolve generation by generation. ✨
7. Pause the simulation whenever you want to inspect the pattern. ⏸️
8. Return to the menu to change the rules or settings. 🏠
9. Generate a new world and experiment again! 🔄

# Simulation Rules 🧬

Each cell changes over time depending on the cells surrounding it.

The project includes four different rule sets, allowing the same starting grid to evolve in completely different ways. Changing the rules can produce stable structures, repeating patterns, expanding formations, chaotic worlds, and other unexpected results.

Experiment with different settings and starting patterns to see what emerges. 🔬✨

# Controls

* Spacebar — Start / Pause the simulation
* Start — Begin or resume
* Stop / Pause — Freeze the current generation
* Random — Generate a random starting world
* Clear — Remove cells from the grid
* Menu — Return to simulation settings
* Grid Click — Add or remove individual cells

# Customization 🎨

The simulator allows you to personalize how your cellular world looks and behaves.

You can adjust:

* 🎨 Cell colors
* 🌑 Background colors
* 🎚️ Simulation speed
* 🧬 Rule set
* ☀️ Light or dark appearance
* 🎲 Starting patterns

This makes it possible to create everything from minimal monochrome simulations to colorful evolving worlds.

# Technical Details

* Built entirely with Python 3
* Uses Python’s built-in tkinter library for the graphical interface
* Uses grid-based cellular automata logic
* Calculates neighboring cells for every generation
* Supports multiple simulation rule sets
* Uses Tkinter event handling for interactive controls
* Includes keyboard and graphical controls
* Dynamically updates the simulation grid
* Supports random pattern generation
* Separates simulation controls from configuration through a menu system
